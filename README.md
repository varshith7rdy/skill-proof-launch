# Remix of Skill Forge Demo

Build a premium, professional frontend prototype for **SKILL2PROVE**, an Academia–Industry platform for Skill Mapping, Skill Verification, Internships and Placements.

This is a **hackathon demo prototype**, so do NOT build login/signup, authentication, database or complex backend. Focus entirely on a polished, interactive UI using realistic mock data.

### HOME PAGE — Role Selection

Create a visually impressive landing page with the headline:

**“Turn Skills Into Proof. Turn Proof Into Opportunities.”**

Short subtitle:

**Connecting Students, Academia and Industry through verified skills and real-world opportunities.**

Below the hero, prominently display exactly **3 large interactive cards/buttons**:

**01 — STUDENT**

Build Skills • Prove Skills • Find Opportunities

**02 — COLLEGE**

Map Skills • Identify Gaps • Improve Placement Readiness

**03 — INDUSTRY**

Discover Talent • Create Challenges • Hire by Skills

When the user clicks a button, immediately switch to that particular dashboard/view. **No login page.**

### STUDENT VIEW

Create a modern dashboard showing:

- Career Readiness Score

- Dynamic Skill Passport

- Skill Graph

- Verified Skills

- Skill Evidence Vault

- Claim → Test → Proof

- Personal Skill Gap Map

- AI Skill Roadmap

- Industry Micro-Missions

- Internship Opportunities

- Proof-Based Resume

- Skill Progress Timeline

Use realistic sample data such as:

**Python — Advanced — Verified**

**Machine Learning — Intermediate — Industry Validated**

**React — Intermediate — Verified**

Make cards, charts and skill graphs visually interactive.

Buttons like **Take Challenge, View Skill Gap, Start Roadmap, Upload Evidence, View Internship, Generate Resume** must work using modals, drawers or interactive state changes.

### COLLEGE VIEW

Create a separate college dashboard showing:

- Department Skill Heatmap

- Industry Demand vs Student Supply

- Curriculum Gap Detector

- Placement Readiness Dashboard

- Faculty Skill Insights

- Emerging Industry Skills

- Industry Collaboration Workspace

- Skill-to-Curriculum Traceability

Include filters for:

**Department | Batch | Skill | Job Role**

Charts and cards should be clickable and reveal additional mock information.

### INDUSTRY VIEW

Create a separate industry/recruiter dashboard showing:

- Competency-Based Job Creation

- Industry Challenge Builder

- Candidate Discovery

- Candidate Skill Comparison

- Skill Requirement Forecast

- Internship-to-Placement Pipeline

- Industry Feedback

Create a searchable candidate list with filters for:

**Skill | Competency Level | Role | Department | Verified Evidence**

Clicking a candidate should open their **Skill Passport** with skills, competency levels, projects, challenge results and verification status.

### SIGNATURE VISUAL

Make **Claim → Test → Proof** one of the most visually impressive sections of the prototype.

Example:

**Python**

Claimed → Tested → Practically Proven → Industry Validated

Also show:

**Skill Freshness:** Recent / Active / Outdated

**Proof Integrity:** Verified

**Industry Validation:** Validated

### UI / UX

- Premium SaaS dashboard design

- Clean white/light background with navy, indigo and subtle gradients

- Modern typography

- Rounded cards

- Smooth transitions and micro-animations

- Interactive charts and progress indicators

- Responsive design

- Minimal but visually rich

- Avoid excessive text

- Use icons and visualizations wherever possible

Add a persistent **“Switch View”** button so judges can instantly switch between **Student / College / Industry**.

Every visible button should perform a meaningful prototype action. Use modals, tabs, dropdowns, filters, animations and mock state changes.

The final result should look like a **real enterprise product demo**, allowing judges to understand SKILL2PROVE within 2–3 minutes without needing any login or backend.
